## 1) المبدأ

Workspace **ليس اشتراكاً منفصلاً** — ميزاته موزّعة على **باقات Rukny الحالية**. لا نبيع «Workspace Starter» منفصلاً عن المنصة.

| العملة | الاستخدام |
|--------|-----------|
| **د.ع (IQD)** | عرض للمستخدم في العراق |
| **USD** | تقدير تكلفة SendGrid وتحليل هامش الربح |

**سعر الصرف المرجعي للتخطيط:** 1 USD ≈ 1,300 IQD

**أسعار المنصة الموحّدة:** احترافية **15,000** · حوت **25,000** · أعمال **40,000** د.ع / شهر

## 5) تكلفة البريد التقديرية (SendGrid — مزوّد الإطلاق الرسمي)

> **مزوّد الإطلاق:** SendGrid **Essentials 50K** = **$19.95/شهر** · **50,000** رسالة · overage **$0.00133/رسالة** (~$1.33/1K).  
> ترقية لاحقة: Essentials 100K = $34.95 · 100,000 رسالة.  
> الإعداد: [WORKSPACE_SENDGRID_SETUP.md](./WORKSPACE_SENDGRID_SETUP.md) · الأرباح: [RUKNY_PROFIT_MODEL.md](./RUKNY_PROFIT_MODEL.md).

### لكل عميل احترافي (استخدام واقعي ~1.5K رسالة/شهر، 3 صناديق)

| البند | USD/شهر |
|-------|---------|
| حصة من اشتراك SendGrid (تقديري) | ~$0.40 |
| إرسال متغيّر داخل الحصة المشتركة | ~$0.60 |
| تخزين S3/DB محلي للبريد | ~$0.05 |
| **الإجمالي التقديري** | **~$1.05** |

**إيراد:** ~$11.54/شهر (15,000 د.ع)  
**هامش بعد بند البريد (واقعي):** ~%90 قبل استضافة ودعم المنصة  

> أسوأ حالة (استنفاد 5K كامل داخل الحصة): تكلفة إرسال نظرية ~$2.00 → ما زال موجباً بقوة على الاحترافية.  
> باقة **الأعمال** بحد 100K خطر على الهامش إن استُنزفت — تحتاج hard cap + إضافات (انظر نموذج الأرباح §7).  
> شحنة «10,000 رسالة بـ 5,000 د.ع» حالياً **قد تخسر** أمام overage SendGrid — راجع توصية الرفع في نموذج الأرباح.

## 6) Freemium (مرحلة 2 — ليس MVP)

```
username@mail.rukny.io
├── 1 صندوق
├── 500 رسالة/شهر
```

```typescript
export const WORKSPACE_LIMITS = {
  FREE:       { domains: 0, mailboxes: 0, sendMonthly: 0, storageBytes: 0 },
  PRO:        { domains: 1, mailboxes: 3, sendMonthly: 5_000, storageBytes: 5_GB },
  WHALE:      { domains: 3, mailboxes: 10, sendMonthly: 25_000, storageBytes: 25_GB },
```
